### Test Role 1: Full-Stack AI / Backend Engineer (Recommended)

**Job Title:**
```
Senior Full-Stack / Backend Engineer (AI Platform)
```

**Job Description Text:**
```
Company: Nexus AI Labs
Role: Senior Full-Stack / Backend Engineer (AI Platform)
Location: Remote / Hybrid

About the Role:
We are looking for a Senior Full-Stack / Backend Engineer to design, scale, and maintain high-throughput backend services and interactive frontend interfaces for our generative AI developer platform. You will collaborate closely with machine learning engineers and product designers to turn LLM workflows into reliable, low-latency microservices.

Key Responsibilities:
- Architect and deploy scalable RESTful and streaming APIs using Python and FastAPI.
- Build clean, accessible, and high-performance web applications using React, Next.js, and TypeScript.
- Design resilient data models and query optimizations on PostgreSQL and Redis for caching and session management.
- Containerize services with Docker and manage deployments across Kubernetes and AWS cloud infrastructure.
- Implement robust CI/CD deployment pipelines using GitHub Actions and Git.
- Monitor application performance, error rates, and system latency with Prometheus and Grafana.
- Collaborate with cross-functional teams in agile sprints, participating in system design reviews and mentoring junior engineers.

Requirements & Qualifications:
- 3+ years of professional backend engineering experience with Python and FastAPI (or Django / Flask).
- Strong command of modern frontend development with React, Next.js, and TypeScript.
- Deep hands-on experience with relational databases (PostgreSQL, SQL) and in-memory caches (Redis).
- Experience containerizing microservices using Docker and orchestration with Kubernetes.
- Solid understanding of distributed systems, cloud computing on AWS (or GCP), and automated CI/CD workflows.
- Familiarity with Machine Learning workflows, LLM integration, and vector embeddings is a strong plus.
- Excellent communication skills, proactive problem-solving mindset, and experience with behavioral STAR framework collaboration.
```

### Test Role 2: Machine Learning & NLP Engineer

**Job Title:**
```
Machine Learning Engineer (NLP & Generative AI)
```

**Job Description Text:**
```
Company: Cortex Intelligence
Role: Machine Learning Engineer (NLP & Generative AI)
Location: Remote

About the Role:
Cortex Intelligence is seeking an experienced Machine Learning Engineer to develop, fine-tune, and deploy state-of-the-art NLP and generative AI models for enterprise search and document intelligence.

Key Responsibilities:
- Design and fine-tune transformer models using PyTorch, Hugging Face, and TensorFlow.
- Build automated data processing, feature engineering, and ETL pipelines using Pandas, NumPy, and Scikit-learn.
- Implement semantic search, dense vector embeddings, and retrieval-augmented generation (RAG) pipelines.
- Deploy low-latency model inference endpoints using FastAPI, Docker, and Triton / ONNX.
- Manage scalable cloud training and evaluation workloads on AWS or GCP.
- Implement continuous model evaluation, tracking drift, accuracy, and latency metrics with MLflow.

Required Skills:
- Proficiency in Python, PyTorch, and deep learning architectures (Transformers, BERT, LLMs).
- Experience with NLP libraries such as Hugging Face, Scikit-learn, and vector databases.
- Strong fundamentals in data manipulation using Pandas, NumPy, and SQL.
- Practical experience deploying ML applications via Docker, FastAPI, and cloud platforms (AWS / GCP).
- Strong algorithmic problem-solving abilities and clear understanding of space/time trade-offs.
```

### Test Role 3: Frontend & UI Engineer

**Job Title:**
```
Frontend Engineer (React / Next.js)
```

**Job Description Text:**
```
Company: Pulse Creative
Role: Frontend Engineer (React & Design Systems)
Location: Remote

About the Role:
We are looking for a detail-oriented Frontend Engineer to craft fluid, accessible, and responsive user experiences for our next-generation web products.

Key Responsibilities:
- Build and maintain modern web applications with React, Next.js, and TypeScript.
- Implement component design systems and responsive layouts using Tailwind CSS.
```
